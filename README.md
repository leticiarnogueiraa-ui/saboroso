# saboroso


## Sobre o projeto

O **Saboroso** é uma plataforma de streaming de culinária desenvolvida como projeto acadêmico do SENAI. O objetivo é facilitar a descoberta de receitas, reunindo conteúdos culinários em um único lugar, com opções de busca e acesso a vídeos de preparo.

## Funcionalidades

- Catálogo de receitas culinárias.
- Busca e filtros para encontrar receitas.
- Página de detalhes das receitas.
- Integração com vídeos do YouTube.
- Cadastro e login de usuários.
- Sistema de favoritos.
- Recuperação de senha.
- Notificação por e-mail em novos cadastros.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- YouTube Data API
- Resend API
